# nzfleet, reference copy

A snapshot of nzfleet, the orchestrator that runs nzela's agent fleet, published so that shunt can be built to replace it. It is not maintained here and takes no changes. The live nzfleet stays in nzela's repository and keeps running the fleet until shunt replaces it.

Start with `skill/SHUNT.md`, which says what to copy, what not to copy, and what is still changing.

The original README is `README-NZFLEET.md`.
